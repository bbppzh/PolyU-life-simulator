# V4 完整改進計劃

日期：2026-10-28（香港時間）
狀態：主要功能和問卷已上線；續玩位置修正已通過桌面瀏覽器深頁重整測試，最終公開版及 iPhone 新修正待復驗。

## 問題與證據

更新前的本地 V4 已有八學期、六個專業、角色記憶、生活預算、成績、像素音樂和結局問卷，但重新整理會遺失當局，問卷入口只在畢業後顯示。專業已有獨立事件，仍可用跨年後續把早期決策連起來；現有畢業頁沒有可下載圖片。這些是程式檢查結果，並非玩家研究或實機測試結果。

## 目標

1. 重整後可恢復同一局，包括待處理結果、學期計劃、亂數狀態、人物關係與收藏；恢復本身不會重算成績或消耗亂數。
2. 開局、故事途中、畢業後均能找到自願回饋入口，問卷可辨識版本與遊玩階段。
3. 每個專業有一條四年連續支線，至少兩個專屬後續決策，早期選擇影響後文與具體取捨。
4. 玩家可以下載含結局、專業、CGPA、代表選擇及像素人物的 PNG 畢業紀念卡。
5. 驗證桌面、手機排版、鍵盤、重整與音樂切頁；真實 iPhone Safari 測試結果與未能驗證的項目分開記錄。

## 範圍與保留

更新現有 `/v4/` 及 V4 離線 HTML，不建立新版本選擇頁。保留 V1–V3.2 的檔案，V4 的紅磚像素風、主要故事、八學期、六專業、天賦加點、預算、角色、成績規則、原創音樂和獨立音量。校園 3D 入口維持撤回。此次不做帳戶、雲端同步、排行榜、追蹤分析或自動對外分享；存檔留在玩家瀏覽器，紀念卡由玩家下載。

## 使用情境與驗收

### A. 自動存檔與續玩（P0）

- 返校玩家在開局畫面看到存檔摘要及「繼續上次人生」。
- 在提交學期計劃、每次決策及繼續故事後儲存，收藏和未提交的計劃草稿也可恢復。
- 以有版本號的存檔格式保存完整資料，檢查大小、欄位、事件位置、數值及參照；損壞或不相容時提示，玩家仍可開始新局。
- 存儲被瀏覽器禁止或容量不足時顯示提示，遊戲仍可玩。新局覆蓋既有存檔須明確確認。
- 音樂在重整／續玩後維持關閉，音量偏好保留；繼續遊戲不觸發瀏覽器自動播放。
- 測試：規劃、主事件、後續事件、結果、畢業五種狀態往返；恢復後與不中斷同路線結果一致。

### B. 途中回饋及問卷（P0）

- 頁首提供「Feedback / 回饋」，另開既有 Microsoft Forms，遊戲分頁保留。
- 表單名稱維持 V4；追加兩個可選問題：遊玩版本（V4／V3.2／其他／不確定）、遊玩階段（設定／大一／大二／大三／大四／已畢業／無法開始）。
- 沿用同一份表單、連結及既有回覆，不傳送玩家姓名、選項或成績；不代交測試回覆。
- 若編輯器需要登入，只在帳戶步驟請使用者操作，其餘工作繼續。

### C. 六個專業的連續支線（P0）

- 接續現有四個年度專業事件；新增大二與大四各一次後續，總計 12 個專業專屬場景。
- DSAI：資料來源／外部評估；Computing：軟件維護／交接；Business：市場證據／啟動規模；Design：使用者回饋／作品集；Engineering：可靠性／測試邊界；Health：去識別證據／溝通與不確定性。
- 每個後續有三個有代價的選擇、前文回應及獨立記錄。支線影響履歷、身心與連結；不在畢業考試鎖分後修改成績。
- 畢業總結能看到支線起點、後續及結果，舊版內容與角色敘事繼續成立。
- 測試所有六專業和三種選擇路徑、種子重播、八學期結算與最終鎖分。

### D. 畢業紀念卡（P0）

- 畢業頁新增紀念卡預覽和「下載 PNG」，沿用原創紅磚、像素校園與人物。
- 包含專業、結局、CGPA、三項狀態及最多三個實際選擇，並註明遊戲模擬成績。
- 下載圖片不依賴網絡字型或外部圖片，不上傳資料；瀏覽器不支援時給清楚提示。
- 長姓名／中英文／長選項可換行，圖片不裁字；輸入視作純文字。

### E. 手機與可及性（P0）

- 320/390px 無橫向溢出，主要控制至少 44px，頁首回饋與音樂按鈕可操作。
- 原有數字鍵、焦點還原、對話框阻擋故事快捷鍵、減少動態效果均保留。
- 核對切頁暫停／回來的音樂狀態、滑桿、續玩及下載操作。
- 真實 iPhone Safari：按實際觀察記錄已通過與未測項目；不把桌面窄視窗當成實機已通過。

## 執行順序與交付

1. 記錄來源及公開檔案雜湊，建立此計劃。
2. 實作可驗證的存檔與還原，再接上續玩／草稿／收藏 UI。
3. 編寫六專業支線及記憶回應，更新事件數、日誌及回顧。
4. 加回饋入口、更新現有表單；實作紀念卡及手機樣式。
5. 跑合適的引擎／存檔／支線測試，實際瀏覽器驗證及圖片檢查，修正後重建網站與離線下載。
6. 只發布此次需要的 V4 與版本介紹變更，核對舊版不變；等待 GitHub Pages 成功後檢查公開頁面，保存截圖與驗證記錄。

## 成功衡量與未決事項

工程驗收以重播一致、存檔錯誤可恢復、六條支線可完成、PNG 可開啟及排版檢查為準。玩家是否更願意完成／重玩，需要真實問卷與試玩才能判斷，這次不填造改善百分比。無使用者指定期限；先完成資料與故事，再驗證與發布。Microsoft Forms 已完成更新；iPhone Safari 已實測部分流程，尚未在手機完成整局及下載 PNG。詳見測試記錄。
